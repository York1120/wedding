# Yuquan & Lingyi · Western Wedding Invitation（西式请柬 · 新人视角）

与 `inv-o`（中式新人请柬）同一婚礼信息、同一邀请人（新人自己），
视觉语言换用 **Ivory Ceremony · 象牙之约**（见 `inv-b/poster-design-western.md`，
与西式海报同源）：象牙棉纸、暖墨、鼠尾草绿、古金烫印，雕版请柬式排版。

- **婚期**:2027年1月26日（星期二 · 农历丙午年腊月十九）午间吉时
- **地点**:湖南省常德市桃源县沙坪镇 · 张府
- **邀请人**:新郎 周煜全 · 新娘 张令仪（英文署名 Yuquan & Lingyi）

## 设计与动效

| 桥段 | 说明 |
|---|---|
| 火漆信封封面 | 轻触火漆印 → 蜡裂两半 + 金屑迸溅 → 封盖 3D 掀开 → 请柬卡从信封抽出 → 信封退场进正页；9 秒未点自动开启 |
| 首屏 | 金环字母花押（Y&L）+ 鎏金流光手写体（Great Vibes）+ 中文名 + 分隔花饰 |
| 请柬卡 | 双细线框 + 四角金饰，英文雕版式请求句 + 中文正式婚帖，逐行错峰入场 |
| 照片 | 罗马拱壁龛（双层鎏金拱缘）+ 慢速 Ken Burns，两侧尤加利枝单笔画出、叶片逐片生长 |
| 信息 | 天/时/分/秒实时倒计时（数字翻动微动效）+ 中英对照信息行 + 导航按钮呼吸光环 |
| 落款 | 火漆印章砸落盖印（回弹 + 双圈涟漪）+ 鎏金署名 |
| 全局 | 金箔光尘上浮、纸张肌理、章节滚出视口时透视渐隐（回滚即恢复）、BGM 开启后自动播放 |

动效全部 CSS/原生 JS，无第三方库;`prefers-reduced-motion` 下整体关闭并直接呈现终态。

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 请柬页面（入口必须叫这个名） |
| `fonts/` | 自托管字体子集（Great Vibes / Cormorant / Noto Serif SC），由 `tools/_build_fonts.py` 生成，不要手改 |
| `share.png` | 微信分享卡片缩略图 500x500，由 `tools/_make_share.py` 生成 |
| `bgm.m4a` | 背景音乐（开启请柬后自动播放，右上角按钮可暂停/继续） |
| `图片1-3.jpg` | 照片位，放本目录即自动显示（罗马拱内） |
| `tools/` | 字体裁剪 / 覆盖检查 / 分享图 / 截图脚本（不参与部署） |

## 修改流程

1. 改 `index.html` 文字（宾客称呼、邀请词等）;
2. **若增删了页面文字**,必须重跑 `python tools/_build_fonts.py` 重建字体子集;
3. 跑 `python inv-w/tools/_check_font_coverage.py inv-w` 确认无缺字（CI 也会查）;
4. 推送 main 自动部署（Cloudflare Workers 静态资产）。

## 注意事项

- 与中式版不同,本版**没有模拟来电开场**,开场即信封;`bell.m4a` 不需要;
- 页面不得引用 Google Fonts 域名,字体必须自托管（本目录已自托管西文字体）;
- 资源文件一律 ASCII 文件名,照片例外（`图片1.jpg` 为页面写死的约定,与各版一致）;
- 部署后确认 head 中 `og:url` / `og:image`（含 secure_url）指向本版线上地址。
