# 周煜全 & 张令仪 · 婚礼请柬(男方家)

中式红金风格电子请柬,**男方父母视角**(父 周小健 · 母 张燕玲),新郎名字在前,微信内直接打开分享。
与 `../结婚请柬制作`(女方父亲视角)互不影响,各自独立部署。

- **代码仓库**:https://github.com/York1120/wedding- (本仓库)
- **线上地址**:待部署(部署后把 head 中 `https://your-new-domain` 三处替换为实际网址)

## 文件结构

| 文件 | 说明 |
|---|---|
| `index.html` | 请柬页面(入口必须叫这个名) |
| `xi.png` | 书法囍字(透明底素材,页面多处引用) |
| `call-icon.png` | 来电灵动岛的 iOS 电话图标(模拟来电开场用) |
| `share.png` | 微信分享卡片缩略图 500x500(已生成「周煜全 · 张令仪」版) |
| `bgm.m4a` | 背景音乐(AAC,接听来电进入封面后自动播放) |
| `bell.m4a` | 来电铃声(来电页循环,接听即停) |
| `fonts/` | 自托管字体子集,由 `tools/_build_fonts.py` 生成,不要手改 |
| `tools/` | 字体裁剪 / 分享图 / 检查脚本(不参与部署) |

照片约定:命名为 `图片1.jpg` / `图片2.jpg` / `图片3.jpg` 放在本目录即可自动显示。

## 待补信息(发布前必改)

1. **宴会地址**:搜索 `男方宴会地址` 共 3 处(信息区地址行 + 高德/百度导航链接),
   替换为实际地址;确认后同步补进 `og:description` 的「周府」处。
2. **部署域名**:head 中 `https://your-new-domain` 共 3 处(og:url + og:image 两行),
   部署后换成实际网址。
3. **恭候时刻**:搜索「恭候」可补充具体时刻(如 恭候 11:00 · 开席 11:58)。

## 修改流程

1. 改 `index.html`(或在照片位放图片);
2. **若增删了页面文字**,必须重跑 `python tools/_build_fonts.py` 重建字体子集
   (脚本会自动下载完整字体并按页面用字裁剪),再跑
   `python tools/_check_font_coverage.py .` 确认无缺字;
3. 名字/样式变了可用 `python tools/_make_share.py .` 重新生成分享卡片;
4. 用 workbuddy 应用重新发布(`workbuddy_sites_deploy`,directory 指向本目录);
5. 微信分享卡片信息在 `<head>` 的 `og:description` / `og:image` 中修改;
   分享地址变化时同步更新 `og:url` / `og:image` 两行。

## 注意事项

- 所有资源文件一律用 ASCII 文件名(中文文件名在 HTTP 层会 404);
- 页面不得引用 Google Fonts 域名(境内直连超时会卡首屏),字体必须自托管;
- 部署前确认 `_fontsrc/`、`_charset.txt` 等中间产物已清理(已在 .gitignore 中);
- 微信会缓存分享卡片,测试时给链接加 `?v=2` 可拿到全新卡片。
